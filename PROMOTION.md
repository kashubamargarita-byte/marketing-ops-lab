# Promotion checklist — Marketing Ops Lab

Not published on the live site (internal working doc). Keep it in the repo so it version-controls alongside the tools; delete or move to a private note later if you don't want it public.

## 1. GitHub-native discovery (done automatically at launch)

- [x] Public repo, MIT license, descriptive `README.md`
- [ ] Add repo **Topics** (Settings → gear icon next to About): `marketing`, `b2b-marketing`, `cmo`, `marketing-calculator`, `saas-metrics`, `cac`, `ltv`, `roas`, `marketing-tools`, `growth-marketing`, `revops`, `martech`
- [ ] Fill in the repo's **About** section (short description + website URL + topics)
- [ ] Star your own repo, pin it on your GitHub profile
- [ ] Submit to relevant "awesome-list" repos (search GitHub for `awesome-marketing`, `awesome-saas`, `awesome-growth-hacking`) via pull request

## 2. On-page SEO/GEO (already built into every page)

- [x] Unique title/meta description per tool
- [x] JSON-LD: WebApplication, FAQPage, BreadcrumbList, ItemList, CollectionPage
- [x] `robots.txt` explicitly allowing GPTBot, PerplexityBot, ClaudeBot, OAI-SearchBot, Google-Extended
- [x] `sitemap.xml`, `llms.txt`
- [ ] Submit sitemap to Google Search Console and Bing Webmaster Tools once the domain is live
- [ ] Request indexing for the homepage + top 3 tool pages manually in GSC for faster first crawl

## 3. Free tool directories (backlinks + direct traffic)

Submit each tool (or the whole collection as one listing where the directory only allows one entry per site):

- [ ] Product Hunt (best as one "launch" post for the whole collection, not per-tool)
- [ ] There's An AI For That (if framed with the AI-crawler angle)
- [ ] SaaSHub
- [ ] AlternativeTo (add as a free alternative to paid calculator/analytics tools)
- [ ] G2 / Capterra (as a free tool listing under the "Marketing Analytics" category, not a full vendor profile)
- [ ] Betalist / Indie Hackers (for the launch story)
- [ ] Free-for.dev or similar dev/marketer free-tools lists
- [ ] Reddit: r/marketing, r/B2BMarketing, r/SaaS — share as a resource, not a hard sell

## 4. Content & social (compounding traffic)

- [ ] LinkedIn post announcing the launch (use the Posting Cadence & SSI Growth Planner tool itself as a meta example)
- [ ] One LinkedIn post per new tool added going forward — short, practical, links to the specific calculator
- [ ] Cross-link from your Devart/Belkins bylined articles where a calculator is relevant to the topic
- [ ] Add the site link to your LinkedIn profile's Featured section

## 5. Ongoing cadence

- [ ] Add 1-2 new tools per month to keep the sitemap fresh and give a reason to re-announce
- [ ] Re-check Search Console monthly for which tool pages are actually getting impressions/clicks — double down on what resonates
