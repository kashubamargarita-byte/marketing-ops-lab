Frequently asked questions

Why calculate both media value and pipeline value?
Media value shows the equivalent paid-search cost you're avoiding — useful for comparing SEO/content investment to a paid channel. Pipeline value shows actual business impact. Reporting only one can over- or under-sell content's contribution.
Where do I find 'average CPC for equivalent keywords'?
Google Ads Keyword Planner, or any SEO tool with paid-difficulty/CPC data (Ahrefs, Semrush) for the keywords your organic pages actually rank for.
Does this include branded search traffic?
You can run it either way — including branded traffic overstates the channel's independent contribution, since some of that traffic would find you regardless. Many teams calculate this for non-branded traffic only.
